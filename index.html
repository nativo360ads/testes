📱 Modo Local (Apenas neste aparelho)

Para que os produtos cadastrados no seu celular apareçam instantaneamente para todas as clientes em outros celulares e computadores, conecte um projeto gratuito no Supabase.

📖 Como criar seu banco gratuito no Supabase em 2 minutos (Passo a Passo)

1. Acesse supabase.com e crie uma conta gratuita com seu GitHub ou e-mail.

2. Clique em "New Project" e dê um nome à sua loja (ex: Aura Boutique).

3. No menu lateral esquerdo, clique no ícone SQL Editor, cole o script copiado no botão acima e clique em RUN.

4. No menu lateral, vá em Project Settings → API e copie a Project URL e a anon / public key.

5. Cole nos dois campos acima e clique em Salvar e Conectar Nuvem. Em seguida, clique em Sincronizar Produtos!
